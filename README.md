# 야자 탈출

야간 자율 학습을 마친 밤, 본관 3·4층을 걸으며 야자 귀신이 낸 문법 문제를 풀고 학교를 빠져나가는 웹 게임입니다. 화법과 언어 수업용입니다.

## 진행 순서

2-7반(야자실) → 2-6반 → 2-5반 → 2-4반 → 2-3반 → (4층 동편 계단) → 2-2반 → 2-1반 → 3층 동편 계단으로 탈출

단원 순서는 음운론(자음 체계 → 모음 체계 → 음운 변동) → 형태론(품사 → 단어 형성과 형태소) → 문장론(문장 성분 → 이어진 문장과 시제)입니다.

교실마다 문제가 놓인 기물(칠판, 교탁, 사물함, 게시판, 창문, 시계, 청소도구함, 핸드폰 충전함)이 다릅니다. `js/data.js`의 `CLASS_SPOTS`에서 바꿀 수 있습니다.

- 교실마다 칠판, 교탁, 사물함 세 곳의 문제를 모두 풀어야 문이 열립니다.
- 특별실과 화장실(교무실, 미술실, 보건 교실, 진로진학 상담실, 학생안전 복지부, 예원학당)은 선택입니다. 풀면 부적을 얻고, 부적은 틀린 보기 두 개를 지워 줍니다.
- 배치도에서 흰색인 곳(컴퓨터활용실, 소강의실2, 연결 통로)은 들어갈 수 없습니다.

## 문제 고치기

`js/data.js`만 고치면 됩니다. 정답은 `opts`의 맨 앞에 적고, 화면에서는 보기를 섞어 보여 줍니다.

## 알아 둘 점

- 진행 기록은 학생 기기의 브라우저에만 저장됩니다. 같은 기기, 같은 브라우저로 이어서 해야 합니다.
- 서버, 계정, 외부 전송이 없습니다.

## 그림 바꾸기

그림은 `assets` 폴더에 있습니다. 같은 이름으로 덮어쓰면 게임에 바로 반영됩니다.

- 캐릭터: `char_player_down/up/left/right.png`, `char_ghost.png` (투명 배경)
- 방: `room_class.jpg` 등 8장 (1152×768). 방 그림을 바꾸면 `js/game.js`의 `LAYOUT`에서 걸을 수 있는 칸과 물건 위치를 다시 맞춰야 합니다.
- 복도: `tile_hall_floor.png`, `tile_hall_wall.png`, `obj_door.png`, `obj_door_locked.png`, `obj_stairs.jpg`
- 기타: `title.jpg`(시작 화면), `obj_charm.png`(부적)

그림을 불러오지 못하면 게임이 도형으로 대신 그립니다.

## 문 자물쇠 수수께끼와 교표

- 교실마다 세 곳의 문제를 다 풀면, 문에 걸린 자물쇠 수수께끼를 풀어야 나갈 수 있습니다. 숫자 자물쇠와 낱말 맞히기 두 가지가 있습니다.
- 수수께끼와 정답, 힌트는 `js/data.js`의 `RIDDLES`에서 고칩니다. 낱말 답은 여러 개를 적어 둘 수 있습니다.
- 장소마다 벽에 교표가 하나씩 걸려 있습니다. 교실 교표 뒷면에는 그 교실 수수께끼의 단서(`clue`)가 적혀 있고, 다른 장소의 문구는 `LOGO_SAY`에서 고칩니다.

## 문제 형식

| 형식 | 쓰는 곳 | 설명 |
|---|---|---|
| 객관식 | 대부분의 물건 | 보기 4개 가운데 고르기 (`qs`) |
| 짝 지우기(사천성) | 2-3반·2-6반·2-1반 사물함 | 같은 무리의 패 두 개를 이어 지우기. 선은 두 번까지만 꺾임 (`mode:"match"`) |
| 받아쓰기 | 2-5반 사물함, 2-2반 교탁 | 표준 발음이나 문장 성분 이름을 직접 입력 (`mode:"type"`) |
| 문 자물쇠 수수께끼 | 교실 문 | 숫자 자물쇠, 낱말 수수께끼 (`RIDDLES`) |

새 형식 문제는 `js/data.js` 맨 아래에 있습니다. 다른 물건도 같은 모양으로 적으면 형식을 바꿀 수 있습니다.

## 부적과 책상

- 부적은 힌트를 보는 아이템입니다. 한 장을 가지고 시작하고, 문제·받아쓰기·짝 지우기·문 자물쇠에서 '부적으로 힌트 보기'를 누르면 한 장씩 씁니다. 세 번 틀리면 부적 없이도 힌트가 나옵니다.
- 부적 얻는 곳: 교실 책상 서랍의 숨은 OX 게임(교실마다 2곳, 세 문제를 모두 맞히면 1장), 특별실·화장실, 귀신의 복습 문제.
- 교실 책상 84개는 모두 다른 문구가 나옵니다. 교실마다 공부 3·먹을거리 2·낙서 3·캐릭터 2·아이돌 굿즈 2개씩입니다. 문구는 `DESK_TEXT`, OX 문제는 `OX_BANK`에서 고칩니다.
