# 야자 탈출

야간 자율 학습을 마친 밤, 본관 3·4층을 걸으며 야자 귀신이 낸 문법 문제를 풀고 학교를 빠져나가는 웹 게임입니다. 화법과 언어 수업용입니다.

## 진행 순서

2-3반 → 2-4반 → 2-5반 → 2-6반 → 2-7반 → (중앙 계단) → 2-2반 → 2-1반 → 동편 계단으로 탈출

- 교실마다 칠판, 교탁, 사물함 세 곳의 문제를 모두 풀어야 문이 열립니다.
- 특별실과 화장실(교무실, 미술실, 보건 교실, 진로진학 상담실, 학생안전 복지부, 예원학당)은 선택입니다. 풀면 부적을 얻고, 부적은 틀린 보기 두 개를 지워 줍니다.
- 배치도에서 흰색인 곳(컴퓨터활용실, 소강의실2, 연결 통로)은 들어갈 수 없습니다.

## 주소

- 학생용: `https://<아이디>.github.io/<저장소>/`
- 교사용: 주소 끝에 `#teacher` → 모든 문 열림, 정답 표시, 장소 목록에서 바로 이동, 기록 저장 안 함

## 문제 고치기

`js/data.js`만 고치면 됩니다. 정답은 `opts`의 맨 앞에 적고, 화면에서는 보기를 섞어 보여 줍니다.

## 알아 둘 점

- 진행 기록은 학생 기기의 브라우저에만 저장됩니다. 같은 기기, 같은 브라우저로 이어서 해야 합니다.
- 서버, 계정, 외부 전송이 없습니다.
