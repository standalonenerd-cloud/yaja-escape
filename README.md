# 야자 탈출

야간 자율 학습을 마친 밤, 본관 3·4층을 걸으며 야자 귀신이 낸 문법 문제를 풀고, 얻은 물건으로 숨겨진 열쇠를 찾아 학교를 빠져나가는 웹 게임입니다. 화법과 언어 수업용입니다.

## 진행 순서

2-7반(야자실) → 2-6반 → 2-5반 → 2-4반 → 2-3반 → (4층 동편 계단) → 2-2반 → 2-1반 → 3층 동편 계단으로 탈출

교실 순서는 학교 배치를 따르지만, **문제는 순서와 상관없이 음운·단어·문장 전체에서 무작위로** 나옵니다.

## 교실 하나를 나가는 흐름

1. 노란 **!** 기물 세 곳에서 문제를 풉니다. 한 곳을 다 풀면 물건 하나를 얻습니다.
2. 물건은 가방(🎒, B 키)에 모입니다. 가방에서 두세 개를 골라 **합치거나**, 보라색 **?** 표시가 뜬 곳에 **씁니다**.
3. 손이 닿지 않는 곳에서 **자물쇠 상자**를 꺼내 수수께끼를 풀면 **교실 열쇠**가 나옵니다.
4. 열쇠를 들고 나가는 문으로 가면 문이 열립니다. 2-1반은 열쇠와 낱말 자물쇠가 둘 다 걸려 있습니다.

| 교실 | 퍼즐 | 물건 |
|---|---|---|
| 2-7반 | 사물함 뒤 틈의 상자 | 새 건전지(손전등 밝히기), 말굽 자석 + 충전 케이블 → 자석 낚싯대 |
| 2-6반 | 시계 위의 상자 | 빗자루 + 철사 옷걸이 + 청테이프 → 갈고리 빗자루 |
| 2-5반 | 칠판의 보이지 않는 글씨 → 태극기 뒤 상자 | 손전등 + 보라 셀로판지 + 고무줄 → 블랙라이트, 물티슈 |
| 2-4반 | 우산꽂이 바닥의 상자 | 깔때기, 생수병, 보리차 보온병(물을 채워 공 띄우기) |
| 2-3반 | 사물함 밑 꾸러미 | 30cm 자 + 양면테이프 → 끈끈이 자, 꾸러미 + 가위 → 상자 |
| 2-2반 | 창가 화분 속 상자 | 분무기 → 비닐장갑 → 플라스틱 숟가락 |
| 2-1반 | 두 동강 난 열쇠 | 핀셋(충전함 틈의 조각), 열쇠 두 조각 + 순간접착제 → 열쇠 |

- 퍼즐, 물건, 합치기는 `js/data.js`의 `ROOMS`(stations·puzzles·recipes)와 `ITEMS`에서 고칩니다.
- 엉뚱한 물건을 쓰면 귀신이 귀띔하고, 세 번 틀리면 힌트가 저절로 나옵니다(물건 퍼즐은 나쁜 귀신이 오지 않습니다). 귀신에게 말을 걸어 "어디로 가야 해?"를 누르면 다음에 할 일을 알려 줍니다.

## 착한 귀신과 나쁜 귀신

- **야자 귀신(착한 귀신)**: 원래 있던 귀신입니다. 길을 알려 주고, 말을 걸면 다음에 할 일을 귀띔합니다.
- **나쁜 귀신**: 흰색 도트 귀신입니다. 아래 경우에 나타나 주인공을 쫓아옵니다. 처음엔 느리지만 점점 빨라져서 결국 잡힙니다.
  - 한 문제(객관식·받아쓰기·짝 지우기·자물쇠 수수께끼)를 **세 번 틀렸을 때**. 예전처럼 세 번 틀려도 힌트가 저절로 나오지 않습니다.
  - 교실에서 **4분 동안 진척이 없을 때**(문제를 맞히거나 물건을 얻으면 시간이 다시 셉니다)
- 잡히면 방금 틀린 문제와 **같은 갈래의 응용 문제**가 나옵니다(예: 시제 문제를 틀리면 다른 시제 문제). 맞혀야 풀려나고, 원래 문제로 돌아갑니다.
- 응용 문제를 틀리면 **착한 귀신이 힌트**를 알려 주고, 두 번째로 틀리면 오답 보기 하나를 지워 줍니다.
- 쫓기는 동안에는 기물을 살피거나 가방을 열 수 없습니다.
- 횟수·시간·속도와 대사는 `js/data.js`의 `BAD_GHOST`에서 고칩니다. 같은 갈래로 묶는 규칙은 `js/bank.js` 맨 아래 `TOPIC_RULES`에 있습니다.
- 교사용 주소(`#teacher`)에서는 '오래 꾸물거림'으로는 나타나지 않습니다.

## 무작위 출제

- 문제는 모두 `js/bank.js`에 있습니다. 객관식 음운 59 · 단어 62 · 문장 61문제, 받아쓰기 32문제, 짝 지우기 12묶음, OX 48문제입니다.
- 객관식 기물 하나에는 음운·단어·문장에서 한 문제씩, 순서를 섞어 나옵니다. 교실마다 기물 하나는 짝 지우기나 받아쓰기가 됩니다.
- 한 학생에게는 은행의 문제를 다 쓸 때까지 같은 문제가 다시 나오지 않습니다. 학생마다, 다시 시작할 때마다 문제가 달라집니다.
- 자물쇠 수수께끼 12개 가운데 7개가 교실마다 무작위로 걸립니다.
- 문제마다 영역 꼬리표(음운·단어·문장)가 붙어 나옵니다.

## 특별실

- 교무실, 미술실, 보건 교실, 진로진학 상담실, 학생안전 복지부, 예원학당은 선택입니다. 무작위 문제 4개를 다 풀면 부적 1장을 줍니다.
- 화장실은 쉬어 가는 곳입니다.
- 배치도에서 흰색인 곳(컴퓨터활용실, 소강의실2, 연결 통로)은 들어갈 수 없습니다.

## 주소

- 학생용: `https://<아이디>.github.io/<저장소>/`
- 교사용: 주소 끝에 `#teacher` → 모든 문 열림, 정답과 필요한 물건 표시, 장소 목록에서 바로 이동, 기록 저장 안 함

## 문제 고치기

`js/bank.js`만 고치면 됩니다. 정답은 `opts`의 맨 앞에 적고, 화면에서는 보기를 섞어 보여 줍니다. 학기 중에는 새 문제를 각 목록의 **맨 끝에** 추가하세요. 중간에 넣거나 빼면 이미 하던 학생의 기록에서 문제가 바뀔 수 있습니다.

## 문제 형식

| 형식 | 설명 | 데이터 |
|---|---|---|
| 객관식 | 보기 4개 가운데 고르기 | `QBANK` |
| 짝 지우기(사천성) | 같은 무리의 패 두 개를 이어 지우기. 선은 두 번까지만 꺾임 | `MATCH_BANK` |
| 받아쓰기 | 표준 발음, 품사·문장 성분 이름 등을 직접 입력 | `TYPE_BANK` |
| 숨은 OX | 책상 서랍. 세 문제를 다 맞히면 부적 | `OX_BANK` |
| 수수께끼 자물쇠 | 숫자 자물쇠, 낱말 수수께끼 | `RIDDLES` (`js/data.js`) |

## 수수께끼와 교표

- 자물쇠 상자(2-1반은 문)에 걸린 수수께끼는 숫자 자물쇠와 낱말 맞히기 두 가지가 있습니다.
- 장소마다 벽에 교표가 하나씩 걸려 있습니다. 교실 교표 뒷면에는 그 교실 수수께끼의 단서(`clue`)가 적혀 있고, 다른 장소의 문구는 `LOGO_SAY`에서 고칩니다.

## 부적과 책상

- 부적은 힌트를 보는 아이템입니다. 문제·받아쓰기·짝 지우기·물건 퍼즐·자물쇠에서 '부적으로 힌트 보기'를 누르면 한 장씩 씁니다. 세 번 틀리면 힌트 대신 나쁜 귀신이 옵니다.
- 부적은 처음에 1장, 교실마다 책상 하나의 서랍에 숨은 OX 게임으로 1장씩(세 문제를 모두 맞히면), 특별실 덤 문제로 1장씩 얻습니다.
- 교실 책상 84개는 모두 다른 문구가 나옵니다. 교실마다 공부 3·먹을거리 2·낙서 3·캐릭터 2·아이돌 굿즈 2개씩입니다. 문구는 `js/data.js`의 `DESK_TEXT`에서 고칩니다.

## 출석 확인과 이름 부르기

- 시작 전에 학년·반·번호·이름을 적습니다. 이 기기의 브라우저에만 저장되고, 결과 화면과 수첩에 나옵니다.
- 귀신 대사에서 `{call}`(지수야/민준아), `{name}`(지수), `{full}`(김지수), `{id}`(2학년 3반 15번)는 학생 이름으로 바뀝니다. 세 글자 이름은 성을 빼고 부릅니다.

## 알아 둘 점

- 진행 기록은 학생 기기의 브라우저에만 저장됩니다. 같은 기기, 같은 브라우저로 이어서 해야 합니다.
- 이번 개편으로 저장 형식이 바뀌어, 예전 판으로 하던 기록은 이어지지 않고 처음부터 시작합니다.
- 서버, 계정, 외부 전송이 없습니다.

## 그림 바꾸기

그림은 `assets` 폴더에 있습니다. 같은 이름으로 덮어쓰면 게임에 바로 반영됩니다.

- 방: `room_class.jpg` 등 8장 (1152×768). 방 그림을 바꾸면 `js/game.js`의 `LAYOUT`에서 걸을 수 있는 칸과 물건 위치를 다시 맞춰야 합니다.
- 복도: `tile_hall_floor.png`, `tile_hall_wall.png`, `obj_door.png`, `obj_door_locked.png`, `obj_stairs.jpg`

그림을 불러오지 못하면 게임이 도형으로 대신 그립니다.
